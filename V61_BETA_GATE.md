# term_6 v6.1-beta Qualification Gate

This release combines beta1 and beta2:

- beta1: typed inter-agent mesh, direct owner change requests, durable cross-project dependencies, automatic dependency wakeups, read-only knowledge lanes, and strict mutation isolation.
- beta2: authoritative versioned integration contracts, explicit consumers, non-authoritative contract forecasts, impact analysis, and automatic consumer notifications.

Release target: `6.1.0b1` / `v6.1-beta`.

Qualification is recorded in `VALIDATION.txt` after the release artifact is built and tested from a fresh extraction and wheel installation.
