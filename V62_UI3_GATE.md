# term_6 v6.2-ui3 Release Gate

## Purpose

v6.2-ui3 fixes the remaining UI reliability and hierarchy problems found on the deployed v6.2-ui2 workbench.

## Root cause fixed

The Workspace previously positioned HTML nodes with runtime inline `style="left:...;top:..."` attributes and `element.style.*` mutations. The web UI intentionally ships with `Content-Security-Policy: style-src 'self'`, so Chromium rejected those updates. The visible result was exactly the deployed failure: project nodes collapsing into the top-left corner, apparent overlap, broken drag movement, and repeated CSP console errors.

v6.2-ui3 keeps the strict CSP and removes the incompatible rendering technique instead of adding `unsafe-inline`.
